# 설정과 합성 자료

이 폴더에는 실제 사람의 대화·계정·인증정보가 없습니다. 모두 문서와 구현 검증을 위한 합성 자료입니다.

| 파일 | 용도 |
|---|---|
| `app-config.example.json` | 최초 실행 mock/off 설정 |
| `message-events.synthetic.json` | 정규화된 이벤트 형태의 예시 |
| `reply-decisions.synthetic.json` | 네 액션의 LLM 출력 예시 |

이벤트 파일은 **kmsg의 원본 JSON 출력이 아닙니다.** 앱 어댑터가 정규화한 뒤 내부 정책 테스트에 사용할 자료형입니다. kmsg 원본 응답 계약은 실제 버전·공식 예시·별도 가짜 MCP 서버로 테스트해야 합니다.

합성 이벤트의 용도:

- baseline 이벤트는 과거 대화에 자동 답장하지 않는 검증에 사용합니다.
- incoming 두 건은 연속 수신 묶음 처리에 사용합니다.
- owner 이벤트는 대기 중 본인 답장 취소에 사용합니다.
- repeat 두 건은 같은 시각·같은 문구의 실제 두 발생을 구별하는 데 사용합니다.
- unknown 이벤트는 작성자 불명 보류에 사용합니다.
- bot 뒤 next 이벤트는 정상 봇 발신 이후 새 묶음과 새 지연을 적용하는 데 사용합니다.

각 시나리오는 독립된 앱 상태에서 필요한 이벤트만 골라 재생합니다. 전체 배열을 하나의 연속 운영 시험처럼 해석하지 않습니다. 시뮬레이터는 설정을 mock 범위에서 활성화할 수 있으나 실제 어댑터를 호출해서는 안 됩니다.

JSON Schema 검증 외에 `docs/CONTRACTS.md`의 의미 규칙과 `TEST_PLAN.md`의 기대 결과를 검증해야 합니다.
