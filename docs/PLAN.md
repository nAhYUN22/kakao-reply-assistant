## 작업 단위 완료 규칙

동작 구현, 해당 위험의 검증, 문서 상태 갱신이 끝난 항목만 체크합니다. 실제 Mac이 없는 환경에서는 코드·mock 검증을 진행하고 실기기 항목만 남겨 둡니다. 모든 항목이 완료될 때까지 임의의 실전송을 실행하는 의미는 아닙니다.


## 2026-11-20 완료 범위

M0/M1 합성 전용 흐름을 구현했습니다. Python 44개, UI/API 10개 자동 테스트와 API smoke·브라우저 수직 흐름을 검증했습니다. 기존 인수 시나리오 49개 전체 완료나 실제 Mac 연동 완료를 의미하지 않습니다. 이후 M2의 저장·읽기 어댑터 코드와 합성 검증까지 추가했습니다. 전체 M2 완료는 아니며, 실제 읽기 파이프라인 통합과 Keychain/실기기 검증이 남습니다. 실제 발송 테스트는 이번 요청에서 금지되어 있습니다.
