# 프런트엔드 에이전트 작업 지침

## 담당

한국어 로컬 설정 화면, 이력, 말투·기억 편집, 시뮬레이터를 구현합니다. `PRODUCT_SPEC.md`의 화면과 `ARCHITECTURE.md`의 API 제안을 실제 계약에 맞춰 연결합니다.

## 필수 기준

- 첫 화면에 모의/실제, off/draft/auto, 대상, 연결 상태를 명확히 보여줍니다.
- 즉시 중지 동작을 눈에 띄게 두고 실제 API와 연결합니다.
- 사용자에게 필요한 상태를 설명합니다. epoch나 outbox 같은 구현 용어는 상세 진단에만 둡니다.
- 저장·전송 성공을 API 확인 전에 표시하지 않습니다.
- '로컬 발신 확인'을 '상대 읽음'으로 바꾸지 않습니다.
- 전송 불명, 빈 상태, 로딩, 오류, 입력 범위, 키보드 조작을 지원합니다.
- CSRF/로컬 세션을 계약대로 처리하고 키를 브라우저 저장소에 보관하지 않습니다.
- 백엔드·공통 스키마·잠금 파일을 임의로 바꾸지 않습니다.
- 실제 대화와 인증정보를 디자인 fixture에 넣지 않습니다.

## 완료 보고

동작 화면, 연결한 API, 재현 절차, 실행한 UI 검증, 아직 연결되지 않은 부분을 명시합니다. 정적 화면만 완성한 상태와 기능 완성을 구분합니다.
